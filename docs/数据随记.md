# 数据随记

数据文件：`用户行为分析.csv`（100000 行 × 13 列）
一行数据 = 一个用户的一次网站会话（session）。

## 字段说明

| 字段名 | 含义 | 取值 |
| --- | --- | --- |
| new_user | 是否新用户 | 1 = 新用户，0 = 老用户 |
| age | 年龄 | 整数 |
| sex | 性别 | Female / Male（另有 `'0'` 表示缺失） |
| market | 市场编号 | 1 / 2 / 3 / 4 |
| device | 设备类型 | mobile / desktop（另有 `'0'` 表示缺失） |
| operative_system | 操作系统 | windows / iOS / android / mac / linux / other（另有 `'0'` 表示缺失） |
| source | 流量来源渠道 | Direct / Seo / Ads（另有 `'0'` 表示缺失） |
| total_pages_visited | 本次会话浏览的页面总数 | 整数 |
| home_page | 是否到达首页 | 0 / 1 |
| listing_page | 是否到达列表页 | 0 / 1 |
| product_page | 是否到达商品详情页 | 0 / 1 |
| payment_page | 是否到达支付页 | 0 / 1 |
| confirmation_page | 是否到达确认页 | 0 / 1 |

## 数据观察记录

- **age 存在异常值**：最大值 123，而均值 30.4、中位数 30、75% 分位 36，最大值明显偏离主体分布，疑似异常值，需要做截断处理。
- **四个分类字段存在哨兵值 `'0'`**：`sex`（773 行）、`device`（133 行）、`operative_system`（217 行）、`source`（123 行）中都混有 `'0'`，它不是正常取值而是缺失值的占位，需要进行处理。
- **补充：活跃度（`total_pages_visited`）按 99 分位数截断**：该字段的 99 分位数为 20，清洗时按「仅保留小于 99 分位数的值」处理，即剔除取值大于等于 20 的行，共剔除 1491 行（占 1.49%）。注意用的是严格小于，所以取值恰好等于 20 的行也被一并剔除。
- **清洗结果**：100000 行经上述三步处理后剩 97274 行，剔除 2726 行（2.73%），13 个字段全部保留。

## SQL 查询结果观察

- **新老用户占比超过 1:2**：老用户 66666 行、新用户 30608 行，老新比约 2.18:1，老用户明显多于新用户。
- **性别占比**：女性 59213 行、男性 38061 行，女男比约 1.56:1，接近 3:2。
- **详情页 → 支付页转化率最低，仅 12.63%**：四段漏斗中最低的一段，是全程流失最严重的位置，每 100 个到达详情页的会话只有约 13 个走到支付页。
- **其次是支付页 → 确认页转化率，仅 27.83%**：第二低的一段。
- **整体转化率只有 1.73%**：从首页一路走到确认页的会话占比。
- **完整四段转化率**：首页 → 列表页 73.69%，列表页 → 详情页 66.85%，详情页 → 支付页 12.63%，支付页 → 确认页 27.83%。
- **各维度平均转化率差异需要关注**：
  - 新老用户：老用户 2.03%，新用户 1.09%，相差近一倍。
  - 年龄：20 岁及以下 2.90%，21-30 岁 2.18%，31-40 岁 1.33%，41 岁及以上 0.17%，随年龄单调下降，41 岁以上几乎不转化。
  - 性别：女性 2.16%，男性 1.07%，相差约一倍。
  - 操作系统：mac 2.76%、android 1.75%、iOS 1.69%、windows 1.62%、other 0.96%、linux 0.63%，最高与最低相差约 4 倍。
  - 来源：Direct 2.15%，Seo 1.18%，Ads 1.18%，自然与付费流量几乎持平且都明显低于直接访问。
